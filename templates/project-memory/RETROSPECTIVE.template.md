# 错误复盘

每个错误使用一个二级标题和下面的标准字段。字段可以先不完整，但自动摄取会把缺项标记为`needs_completion`，不会自动晋升。

## {{DATE}} · {{TITLE}}

- 场景：{{SCENARIO}}
- 我做错了什么：{{MISTAKE}}
- 用户如何纠正：{{OWNER_CORRECTION_OR_NONE}}
- 根因：{{ROOT_CAUSE}}
- 影响：{{IMPACT}}
- 以后必须这样做：{{RULE}}
- 可验证的防复发动作：{{VERIFICATION}}

## 写入边界

- 项目事实和一次性事故留在项目仓库。
- 自动摄取只生成候选，不等于批准进入个人Profile。
- 晋升需要两个不同origin的支持证据，或“原文存在用户明确纠正 + 人工审阅标记高影响”。
- 不得在复盘中写密钥、Cookie、真实隐私数据或大段受版权保护内容。
